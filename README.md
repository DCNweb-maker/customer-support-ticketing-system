# Customer Support Ticketing System

## Description
A comprehensive customer support ticketing platform designed to manage, track, and resolve user requests efficiently.

## Main Features
- Ticket creation and assignment workflows.
- User role management (e.g., Admin, Agent, Customer).
- Real-time ticket status tracking.

## Installation / Setup Instructions
1. Clone this repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to launch the local development server.

## User Roles
- **Customer:** Submits support requests and views history.
- **Agent:** Responds to tickets and updates progress statuses.
- **Admin:** Manages user roles and system-wide configurations.

## Ticket Workflow
1. **Created:** Ticket is submitted by a customer.
2. **Assigned:** System or admin routes the ticket to an active agent.
3. **In Progress:** Agent updates logs while working on a solution.
4. **Resolved:** Ticket is closed once the user's issue is fixed.
